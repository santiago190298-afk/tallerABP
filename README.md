# Sistema de Almacenamiento Seguro para Pequeñas Empresas

## Descripción

Proyecto de computación en la nube enfocado en el almacenamiento y protección de información empresarial mediante servicios AWS.

## Problema

Las pequeñas empresas presentan riesgos asociados a la pérdida, acceso no autorizado y falta de respaldo de la información.

## Solución

Se implementó una arquitectura basada en:

- Amazon S3
- AWS IAM
- AWS KMS
- AWS Backup
- CloudWatch
- SNS
